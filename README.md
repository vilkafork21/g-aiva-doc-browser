# G-AIVA

В данную ноду приходит отчет о разработке, тестовая корзина и опционально ответ от пользователя. На основе полученной информации собирается карточка бизнес-процесса, в которой хранится полезная информация из отчета, а также информация о тестовой корзине, необходимые для проведения качественного анализа

---

## Поддерживаемые LLM
* GigaChat

Для того, чтобы GigaChat работал с API OpenAI используется прокси `gpt2giga` (недоступен через sberosc). gpt2giga поднимает отдельный сервер на `http://127.0.0.1:8090` который нужно установить как base_url в клиенте OpenAI. gpt2giga необходимо поднимать в отдельном процессе 

* Opensource LLM из SberDS

Также есть возможность использовать open-source LLM из SberDS. API ai-gateway поддерживает эндпоинты vllm и OpenAI, поэтому отдельно код для них писать не требуется. Для них в клиенте OpenAI в качестве base_url нужно использовать `http://sds-ai-gateway:8097/api/v1`.
